# Brand Promo

Read `../references/h3-production-contract.md` before authoring.

Create short promotional scenes from user-provided or verified brand assets. Do not impersonate a brand from approximate material, invent claims, or hide an absent product behind generic effects.

## Required intake

Use the refinement sheet to collect what is not already known:

- campaign objective, audience, channel, aspect ratio, and total duration;
- exact product/company name, message, CTA, visible copy, narration language, and disclaimers;
- authorized logo, product, packaging, UI, typography, palette, footage, and official-source references;
- which claims/features are verified and which material is conceptual;
- audio preference: effects, native score, dialogue/voiceover, or silence.

Ask only about missing decisions that change the result. If identity-bearing assets are missing, request originals instead of approximating them. User uploads are sufficient for concept planning; flag concrete publication or authenticity risks without repeatedly blocking the workflow.

## Brand truth and provenance

Before creative planning, separate locked facts from creative choices. Record every identity-bearing asset with a stable role, source note/path, verification status, and any rights caveat. Prefer user originals, official brand/product sources, company-controlled media, then licensed partner material. Do not use thumbnails, logo aggregators, fan recreations, or generated substitutes as proof.

Lock logo geometry and clear space, fonts or observable typography behavior, palette, product/UI geometry, official names, feature wording, metrics, slogans, CTA, and disclaimers. Procedural gradients, grids, particles, masks, and transition geometry are allowed only as supporting motion.

## Direction gate

If direction is not specified, have the local formatter propose two or three concise spines and recommend one:

- SaaS/AI: intent → mechanism → capability → useful output → proof → CTA;
- physical product: hero reveal → interaction → feature macro → use → result → packshot;
- service/company: context → process → evidence → outcome → promise;
- image-led brand: authentic image → motif → benefit → emotional payoff → logo.

Do not generate until one spine and the exact visible copy are resolved. For a production request, present a compact truth sheet, reference roles, and beat plan before queuing H3.

## H3 scene plan

OpenMagia generates at 24 fps and at most 15 seconds per scene. Use 4–7 major beats only when the duration supports them; otherwise choose fewer readable beats. For each beat define time range, visual owner/reference, primary action, product proof, exact copy and hold, color state, transition, and motion phase. Maintain one dominant action per beat and reserve a stable final logo/CTA hold.

Use Ref2VA for product or brand design fidelity. Use first-frame continuation for an approved layout or chained shot. The local model may improve staging, lensing, lighting, motion, and transitions, but it must not rewrite facts, copy, claims, reference roles, duration, or brand identity. OpenMagia owns final H3 schema and timing validation.

Prefer native H3 audio for a self-contained reel. Request separate controllable narration/music only when the project needs replacement or remixing later; never duplicate a native soundtrack with an independent track.

## Verification and delivery

Check authenticity, claim accuracy, copy readability, aspect ratio, duration, language, product visibility, unstretched logos, clear CTA, coherent motion, and audio. Deliver the generated scene(s), assembly order, truth/provenance summary, copy list, and any rights caveat.

Failure recovery: replace an approximate logo/product/UI with an authorized source; add concrete proof when the result is generic; reduce simultaneous actions when chaotic; shorten holds when slow; never polish an imitation.
