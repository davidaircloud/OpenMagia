# Album and Theme Identity

Read `../references/music-production-contract.md` before authoring.

Make several songs belong together. There is no artist model, no voice clone,
and no reference recording to condition on, so coherence is produced the way a
label produces it: by reusing a written anchor, the same players, the same
production words, and controlled variation.

## The anchor card

Write the release anchor once and reuse it verbatim: language, genre
vocabulary, the named ensemble, the production character (`tape saturation,
close-miked, dry room`), the vocal description, and the palette of moods. This
fragment goes into the style string of **every** track on the release, in the
same order. Paraphrasing the anchor is the most common way a release comes
apart.

## Motif continuity

A theme that must recur goes into ABC so pitches carry across tracks rather
than being re-invented per song. Where the theme may vary, write the variation
instruction in the style tags (`same theme, second time in triple time, cello
takes the melody`) and keep `melody` planning so the tune survives.

## Variation ledger

Track each generation: seed, plan mode, guidance, the anchor fragment, and the
single element changed from the previous take. One changed variable per
revision. Two changes at once make a comparison meaningless, and the reviewer
cannot tell the release which knob mattered.

## Sequence and review

Audition the release in order, not track by track. Check that the anchor
vocabulary is audible in every track, that tempos give the record a shape, that
vocal description stays one singer unless a feature is intended, and that
transitions between tracks are deliberate. Where one track drifts, fix it by
restoring the anchor fragment first and only then by changing the lyric or the
seed.

## Limits to state out loud

This skill cannot match a reference recording, clone a voice from a sample, or
guarantee identical singers between songs. Coherence comes from shared written
direction plus seeds, and from revising one variable at a time.
