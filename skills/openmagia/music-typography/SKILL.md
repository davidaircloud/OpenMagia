# Music Video Typography

Read `../references/h3-production-contract.md` before authoring.

Create music-video scenes where exact lyric typography is timed, spatially intentional, and subordinate to comprehension.

## Intake and rights-aware scope

Use the refinement sheet to collect the exact user-provided lyric excerpt, language, vocal timing or beat map, music file/reference, performer and environment references, visual tone, duration, aspect ratio, platform safe area, and subtitle/typography goal. Do not guess missing lyrics or provide additional copyrighted lyrics. Ask for timestamps or an audio file when precise synchronization matters.

Separate references into performer identity, wardrobe, environment, graphic/type language, and music timing. Lock exact spelling, capitalization, punctuation, line breaks, and phrase order.

## Concept gate

Have the local formatter propose two or three treatments when direction is open: type as environmental object, projected/light type, editorial overlay, hand-rendered type, or dimensional graphic space. Each proposal must explain performer relationship, readability, and beat behavior. Confirm the treatment if it changes the intended tone.

## Timing ledger

For every phrase record vocal/beat start, type entry, fully readable state, minimum hold, exit, position, scale, contrast, and interaction. Keep one primary phrase active unless deliberate overlap is readable. Long lines must be split at semantic or musical boundaries, never flashed in tiny type.

Map H3 scenes at 24 fps. Each scene defines performer action, camera, environment, lyric events, beat accents, outgoing pose/composition, and continuity handoff. Use beat-reactive scale, tracking, masks, perspective, or physical integration only when the exact text remains stable.

The local formatter may add camera, performance, transition, and spatial typography detail but cannot alter lyrics, timings, identity, or reference roles. OpenMagia validates scene duration, cut ranges, and audio intent.

## Production and QA

For multi-scene work, preserve performer identity, wardrobe, screen direction, palette, type family, scale hierarchy, and transition motif. Prefer native H3 audio only when it is the intended music source; if syncing to supplied music, keep the generated visual plan aligned and use the external track in assembly.

Review at normal speed for exact words, order, hold time, safe area, contrast, occlusion, performer continuity, and beat sync. If letters mutate, shorten phrases and reduce transformation; if readability competes with action, simplify performance/camera; if timing drifts, regenerate the smallest affected scene.
