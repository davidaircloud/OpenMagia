# Minimalist Product Ad

Read `../references/h3-production-contract.md` before authoring.

Create restrained product films whose credibility comes from exact geometry, materials, and observable use—not invented features.

## Intake and locks

Use the refinement sheet to resolve the exact variant, campaign goal, one selling point, use context, aspect ratio, duration, copy/CTA, audio, and required final packshot. Request clear product references covering silhouette, front/label, important sides, controls, and material finish when those details matter.

Build a product lock before directing motion: proportions, component placement, seams, ports, controls, label spelling, finish, reflectivity, color, packaging, and forbidden additions. Separate verified claims from mood language. Never invent ingredients, specifications, awards, compatibility, performance, or functions.

## Choose a film structure

Have the local formatter recommend one structure when unspecified:

- material proof: surface macro → tactile interaction → light response → hero;
- functional proof: user action → mechanism → observable result → packshot;
- design reveal: silhouette → component details → full rotation → logo/CTA;
- context contrast: problem state → product introduction → improved state → hero.

Present the chosen structure and exact copy before generation when the user asked for a finished ad.

## Shot design

Keep each H3 scene within 15 seconds at 24 fps. Use only the number of cuts needed for readable proof. Give every cut a product-owned purpose, time range, lens/framing, motion, light behavior, label visibility, transition, and final state. Prefer macro glides, measured arcs, turntable motion, rack focus, controlled reveals, and motivated light sweeps.

Reflections, contact shadows, liquids, particles, and moving parts must follow product geometry and material physics. Avoid rubbery deformation, duplicated components, swimming labels, implausible hinges, unexplained scene changes, and decorative motion that hides the product.

Use Ref2VA and explicitly state what each image governs. Use a first frame when continuing an approved packshot or composition. The local formatter may add studio staging, camera, micro-motion, lighting, and foley but cannot change the product lock, claims, copy, or reference roles.

## Audio and verification

Favor clean tactile foley—clicks, fabric, glass, metal, packaging, mechanism—and restrained ambience. Add music only when it supports rather than overwhelms material detail. Use no speech unless approved copy requires it.

Verify geometry, label stability, colors, materials, claim accuracy, readable copy, safe framing, duration, audio, and a stable final packshot. If fidelity fails, simplify motion, increase reference coverage, or regenerate from a stronger approved frame; never correct the product by inventing detail.
