Connecting to OpenMagia…

  1. In OBS, add macOS Screen Capture in Window mode and choose Preview · project name. On Windows or Linux, use Window Capture. Crop browser chrome if it is included, or double-click the picture for fullscreen.
  2. Capture OpenMagia’s browser audio once. This is the complete timeline mix, including every MP3, overlapping clip, fade, volume change and loop—not just one media file. On macOS 13+, use macOS Audio Capture (OBS 30+) for the browser application, or the audio included by macOS Screen Capture.
  3. Add Audio Input Capture, name it Link 2 Pro Audio, and select the Insta360 Link 2 Pro microphone. Keep this source separate so its gain, mute, monitoring and latency can be controlled independently.
  4. Press Play in OpenMagia. Enable Loop to repeat the whole timeline. The Preview window follows effects, fades, play/pause and seeks.

Keep both browser windows open and unminimized. Use a separate visible browser window for the editor during a set. Test a short OBS recording and check both its picture and audio meter before going live.

Timeline audio is heard once, from the editor. Keep the live microphone in OBS so it has independent gain, mute, monitoring and latency control. Voice cleanup and loudness normalization are export-only. This plugin uses window capture; pasting the editor URL into OBS Browser Source creates a separate player and does not mirror your live edit.
