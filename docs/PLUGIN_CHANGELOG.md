# Plugin platform changelog

## 0.1.0 — 2026-08-28

- Added floating preview-toolbar entry and side-sheet plugin manager.
- Added unpacked manifest loading from independent repositories.
- Added explicit capability review, enable/disable registry, missing-source handling, and removal without deleting source.
- Added a sandboxed, draggable, resizable, modeless plugin UI runner and background generation-event runtime.
- Added safe MIME serving for plugin HTML, JavaScript, CSS, JSON, SVG, and image assets.
- Added host-checked context, storage, logging, email, and iMessage bridge methods.
- Added in-app development log and placeholder Store tab.
- Added framework-free SDK, authoring/security documentation, and the external Generation Notifier example.
